fandOS

Estoy desarrollando fandOS, mi app privada para gestionar y organizar mi día en iPhone, iPad y Mac. La desarrollo con la metodología SDD, mi propio agent-kit y distintos proveedores de IA.

agent-kit

agent-kit es un conjunto de reglas, herramientas e instrucciones para agentes de IA que uso a diario para desarrollar. Nace de la necesidad de coordinar distintos proveedores de IA para que trabajen juntos bajo mis reglas y mi estilo de desarrollo. Claude Code coordina y reparte las tareas, y Codex revisa cada cambio.

Incluye una herramienta de línea de comandos en JavaScript para Node.js que instala las reglas y skills, consulta el consumo de cada proveedor con ak usage y registra los fallos con ak report. El código es privado.

JavaScript · Node.js · Claude Code · Codex

Ejemplo de uso con cifras ficticias.
