Backend en sistemas empresariales

Desde julio de 2025 trabajo en Cygnus Source, en Madrid. Mantengo aplicaciones que ya están en producción y desarrollo una plataforma que conecta asistentes de IA con los sistemas de la empresa.

En esa plataforma desarrollo asistentes conversacionales, clientes y servidores MCP y microservicios detrás de un gateway. Trabajo con Java y Spring en el backend y también desarrollo el frontend en Angular.

Los servicios en los que trabajo siguen una arquitectura hexagonal. En el frontend escribo pruebas con Vitest y Playwright. Para desarrollar uso agentes a diario, con Claude Code y OpenSpec.

agent-kit

He creado agent-kit porque trabajo con Claude Code y Codex a la vez. Es una herramienta de línea de comandos en JavaScript para Node.js: consulta el consumo de ambos y, con ak route, recomienda a cuál encargar cada tarea.

ak run ejecuta un encargo acotado en Codex y guarda su estado y un traspaso para retomarlo si se interrumpe. Con ak team, las sesiones mantienen un tablero local y reservan su parte antes de escribir. El código es privado.

JavaScript · Node.js · Claude Code · Codex
